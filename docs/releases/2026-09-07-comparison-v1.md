## Included Features

- **Multi-Category Evidence Exploration:** Interactive comparisons across all six core categories: Environment, Reliability, Economics, Human Impact, Security, Technical.
- **Scientific Honesty Controls:** Direct units, clear methodology indicators, accessible tables, and explicit provenance via DataPassport (`atom-dataset-environment` to `atom-dataset-technical`).
- **5 Complexity Tiers:** Progressive explanation depth (Kid, Simple, Curious, Technical, Expert) with persistent preference handling and authoritative URL overrides.
- **Robust URL State & Sharing:** Canonical URL serialization with automatic error recovery for corrupted or deprecated URL parameters.
- **Accessible & Responsive:** Verified on mobile (375px), desktop (1280px), high zoom (200%), dark mode, and reduced motion.
