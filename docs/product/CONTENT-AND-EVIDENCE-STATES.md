# Content and Evidence States

## Missing Comparable Evidence

> We do not currently have reliable comparable data for this metric and technology.

Offer removal, another metric, and the source limitation record.

## Methodological Mismatch

> These estimates use materially different methodologies and should not be interpreted as directly equivalent.

Expose the differing boundaries and what a fair comparison would require.

## Global Fallback

> Country-level evidence is not available for this metric. Showing global evidence.

Never label global observations as country-specific.

## Source Unavailable

> Source currently unavailable. Showing the last verified value from YYYY-MM-DD.

The application supplies the actual verification date. If no verified cached value exists, show the missing-evidence state.

## Stale Evidence

State the last verification date and why the source is considered stale. Stale evidence remains visible only when the publication policy permits it and its status is prominent.

## Disputed Evidence

Show the selected representative value, credible alternatives, reasons for disagreement, broad agreement, and remaining uncertainty. Do not convert disagreement into a confidence score.

## Correction

Material corrections identify the affected claim, prior dataset version, corrected version, reason, date, and whether public interpretation changed.
