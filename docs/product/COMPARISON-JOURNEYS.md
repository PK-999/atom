# Comparison Lab User Journeys

## Casual Visitor

1. Open `/compare` and receive the useful default comparison.
2. Read the chart title, direct values, units, and short L3 interpretation without configuration.
3. Change one technology or metric using a plainly labeled control.
4. Open “Why this number?” when curious.
5. Leave with a trade-off, not a prescribed winner.

Success: the default is understandable without opening a drawer, while the source remains one action away.

## Student

1. Choose a metric or follow a shared comparison.
2. Open its definition and methodology summary.
3. Inspect the Data Passport for geography, period, boundary, representative rule, and source.
4. Follow the source or study route.
5. Switch complexity without losing the comparison.

Success: the student can reconstruct why the displayed value was selected.

## Technical Visitor

1. Enter L4 or L5.
2. Switch from Typical to Range or Raw.
3. Inspect observation-level methods, boundaries, units, and transformations.
4. Identify incompatible observations and licensing limitations.
5. Download data only when its license permits redistribution.

Success: aggregation never hides the source observations or interval meaning.

## Skeptical Visitor

1. Open “Challenge this number.”
2. Compare the representative observation with credible alternatives.
3. Read why values differ and what remains uncertain.
4. Follow primary sources and inspect known limitations.

Success: disagreement is explained without false balance or false certainty.

## Mobile Visitor

1. Receive a vertical comparison with direct labels and values.
2. Open source and metric selectors in focused bottom sheets.
3. Read the narrative and table without horizontal scrolling.
4. Open evidence in a full-height sheet and return to the originating control.
5. Share or reload the URL with state preserved.

Success: mobile retains all evidence and comparison capabilities available on desktop.
