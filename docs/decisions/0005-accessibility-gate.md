# ADR 0005: Accessibility as a Release Gate

- Status: Accepted
- Date: 2026-08-30

## Decision

Accessibility is a release requirement. Every visualization has a narrative summary and table or textual alternative. Critical information cannot depend on hover, motion, color, or pointer input.

Release verification includes keyboard-only use, visible focus, focus restoration, WCAG AA contrast, semantic labels, 200% zoom, reduced motion, screen-reader summaries, and approximately 44px touch targets where practical.
