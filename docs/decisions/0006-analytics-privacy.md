# ADR 0006: Privacy-Conscious Analytics

- Status: Accepted
- Date: 2026-08-30

## Decision

Collect only product-interaction events defined by the Comparison Lab specification. Do not collect names, email addresses, free-form content, precise location, cross-site identifiers, or scientific/ideological profiles.

Event properties may include metric identifiers, technology counts, display mode, unit mode, complexity level, and release version. Analytics failure must never block learning or evidence access.
